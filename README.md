# JELK Digital – Website

- Öffentlich unter https://jelkdigital.de über GitHub Pages (Branch `main`, Ordner `/`), ohne Passwortschutz.
- Zusätzlich lädt jede Änderung auf `main` die Seite per FTP auf den alten Webspace (`.github/workflows/upload.yml`).
- `alt/` wird nicht per FTP hochgeladen (nur Backups und Bausteine), ist über GitHub Pages aber erreichbar.
- Impressum und Datenschutz stehen in `index.html` (Hosting: GitHub Pages, Domain + Mail: Variomedia).
